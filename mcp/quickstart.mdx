<Steps>
  <Step title="Consigue tu API key">
    La key de Nippy empieza con `npk_` y determina a qué negocio tienes acceso.

    ```text
    https://console.nippy.la/settings/api-keys
    ```

    <Note>
      Tu key `npk_` da acceso a los datos de tu negocio. Trátala como una contraseña.
    </Note>
  </Step>

  <Step title="Agrega el servidor a tu cliente">
    El endpoint MCP de Nippy es:

    ```text
    https://ms.nippy.la/cognitive-layer/mcp
    ```

    <Tabs>
      <Tab title="Claude Desktop">
        Abre tu archivo de configuración:

        **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`

        **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`

        ```json
        {
          "mcpServers": {
            "nippy": {
              "url": "https://ms.nippy.la/cognitive-layer/mcp",
              "headers": {
                "X-API-Key": "npk_tu_api_key_aqui"
              }
            }
          }
        }
        ```

        Reinicia Claude Desktop y prueba con: "Muéstrame qué ruletas tengo activas".
      </Tab>

      <Tab title="Cursor">
        Ve a **Settings** > **MCP** y agrega un nuevo servidor:

        ```json
        {
          "mcpServers": {
            "nippy": {
              "url": "https://ms.nippy.la/cognitive-layer/mcp",
              "headers": {
                "X-API-Key": "npk_tu_api_key_aqui"
              }
            }
          }
        }
        ```

        Guarda, reinicia el workspace y prueba con: "¿Cuántos flows de registro tengo y cuál es su tasa de conversión?".
      </Tab>

      <Tab title="OpenClaw">
        Usa el mismo formato que Claude Desktop:

        ```json
        {
          "mcpServers": {
            "nippy": {
              "url": "https://ms.nippy.la/cognitive-layer/mcp",
              "headers": {
                "X-API-Key": "npk_tu_api_key_aqui"
              }
            }
          }
        }
        ```

        Prueba con: "Dame un resumen de los cursos que tengo y cuántos alumnos lleva cada uno".
      </Tab>

      <Tab title="Hermes Agent">
        Edita `~/.hermes/config.yaml`:

        ```yaml
        mcp_servers:
          nippy:
            url: https://ms.nippy.la/cognitive-layer/mcp
            headers:
              X-API-Key: npk_tu_api_key_aqui
        ```

        Prueba con: "¿Hay productos con stock bajo? Muéstrame cuáles".
      </Tab>
    </Tabs>
  </Step>

  <Step title="Haz tu primera consulta">
    Una vez conectado, el agente puede usar las tools disponibles para tu negocio.

    Ejemplos:

    - "¿Cuántos premios se canjearon este mes vs el mes pasado?"
    - "Crea una ruleta de bienvenida con 3 premios: mochila, descuento del 10% y seguir participando"
    - "¿Quiénes terminaron el curso de inducción esta semana?"
    - "Registra una entrega de 5 camisetas a María en el centro de Monterrey"
  </Step>
</Steps>

## Llamada directa

Si prefieres invocar las tools manualmente, el servidor acepta JSON-RPC 2.0. Cada petición debe incluir el header `X-API-Key`.

```bash
curl -X POST https://ms.nippy.la/cognitive-layer/mcp \
  -H "Content-Type: application/json" \
  -H "X-API-Key: npk_tu_api_key_aqui" \
  -d '{
    "jsonrpc": "2.0",
    "id": 1,
    "method": "tools/list"
  }'
```

<Warning>
  Nunca incluyas `businessId` en pipelines de analytics ni en otros parámetros. El servidor lo inyecta automáticamente a partir de tu API key.
</Warning>
