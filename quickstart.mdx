## Paso 1: Obtén tu API key

Toda autenticación al MCP requiere una **Nippy API Key** (`npk_*`). Esta key está ligada a tu negocio — el servidor resuelve automáticamente tu `business_id` a partir de ella, sin que tengas que pasarlo en cada llamada.

Para obtener tu key, contacta al equipo de Nippy o accede desde la Consola:

```
https://console.nippy.la/settings/api-keys
```

<Note>
  Las API keys tienen el prefijo `npk_`. Guárdalas con cuidado: tienen acceso completo a los datos de tu negocio. Nunca las compartas ni las expongas en repositorios públicos.
</Note>

## Paso 2: Agrega el servidor a tu cliente MCP

<AccordionGroup>
  <Accordion icon="robot" title="Claude Desktop">
    Edita el archivo de configuración de Claude Desktop:

    **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`

    **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`

    ```json
    {
      "mcpServers": {
        "nippy": {
          "command": "npx",
          "args": ["-y", "@anthropic/server-mcp-everything", "--transport", "streamableHttp", "https://ms.nippy.la/cognitive-layer/mcp"],
          "env": {
            "MCP_BEARER_TOKEN": "npk_tu_api_key_aqui"
          }
        }
      }
    }
    ```

    Reinicia Claude Desktop. El ícono de herramientas debe aparecer en el chat.
  </Accordion>
  <Accordion icon="code" title="Cursor">
    Abre la configuración de MCP en Cursor y agrega:

    ```json
    {
      "mcpServers": {
        "nippy": {
          "url": "https://ms.nippy.la/cognitive-layer/mcp",
          "headers": {
            "X-API-Key": "npk_tu_api_key_aqui"
          }
        }
      }
    }
    ```

    Guarda y reinicia el workspace. Las tools de Nippy aparecerán disponibles en el agente.
  </Accordion>
  <Accordion icon="terminal" title="Cliente HTTP directo">
    El servidor acepta peticiones JSON-RPC 2.0 sobre HTTP. Cada petición debe incluir el header `X-API-Key`:

    ```bash
    curl -X POST https://ms.nippy.la/cognitive-layer/mcp \
      -H "Content-Type: application/json" \
      -H "X-API-Key: npk_tu_api_key_aqui" \
      -d '{
        "jsonrpc": "2.0",
        "id": 1,
        "method": "tools/list"
      }'
    ```
  </Accordion>
</AccordionGroup>

## Paso 3: Haz tu primera llamada

Una vez conectado, el agente tendrá acceso a todas las verticales. Prueba con una consulta simple. En Claude Desktop o Cursor escribe:

> "Muéstrame el catálogo de stock de mi negocio"

El agente usará `supply_list_stocks` automáticamente y te devolverá los productos registrados con sus niveles de inventario.

### Ejemplo de llamada directa (JSON-RPC)

Si prefieres invocar una tool manualmente:

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "analytics_execute_pipeline",
    "arguments": {
      "collection": "roulettesMaterializedView",
      "pipeline": [
        {
          "$match": {
            "createdAt": {
              "$gte": "2026-01-01T00:00:00Z",
              "$lte": "2026-05-08T23:59:59Z"
            }
          }
        },
        {
          "$group": {
            "_id": null,
            "total": {"$sum": 1}
          }
        }
      ]
    }
  }
}
```

<Note>
  No incluyas `businessId` en pipelines de analytics ni en ningún parámetro de tool. El servidor lo inyecta automáticamente a partir de tu API key.
</Note>
