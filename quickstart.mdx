## Paso 1: Consigue tu API key

La key de Nippy empieza con `npk_` y es lo que le dice al servidor quién eres y a qué negocio tienes acceso. No tienes que pasar IDs de empresa ni nada — la key ya sabe de cuál eres.

La obtienes desde la Consola:

```
https://console.nippy.la/settings/api-keys
```

<Note>
  Tu key `npk_` te da acceso completo a los datos de tu negocio. Trátala como una contraseña: no la subas a GitHub, no la compartas.
</Note>

## Paso 2: Agrega el servidor a tu cliente

Elige tu cliente y copia la config. En todos los casos el servidor está en:

```
https://ms.nippy.la/cognitive-layer/mcp
```

## Paso 3: Listo, ya puedes preguntar lo que quieras

Una vez conectado, el agente tiene acceso a todas las tools de Nippy. No necesitas saber cómo se llaman ni qué parámetros usan — solo pide lo que necesitas en español y el agente decide qué tool usar.

Algunas ideas para empezar:

- "¿Cuántos premios se canjearon este mes vs el mes pasado?"
- "Crea una ruleta de bienvenida con 3 premios: mochila, descuento del 10% y seguir participando"
- "¿Quiénes terminaron el curso de inducción esta semana?"
- "Registra una entrega de 5 camisetas a María en el centro de Monterrey"

## Llamada directa (avanzado)

Si prefieres invocar las tools manualmente, el servidor acepta JSON-RPC 2.0. Cada petición debe incluir el header `X-API-Key`:

```bash
curl -X POST https://ms.nippy.la/cognitive-layer/mcp \
  -H "Content-Type: application/json" \
  -H "X-API-Key: npk_tu_api_key_aqui" \
  -d '{
    "jsonrpc": "2.0",
    "id": 1,
    "method": "tools/list"
  }'
```

Para llamar una tool directamente:

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "analytics_execute_pipeline",
    "arguments": {
      "collection": "roulettesMaterializedView",
      "pipeline": [
        {
          "$match": {
            "createdAt": {
              "$gte": "2026-01-01T00:00:00Z",
              "$lte": "2026-05-08T23:59:59Z"
            }
          }
        },
        {
          "$group": {
            "_id": null,
            "total": {"$sum": 1}
          }
        }
      ]
    }
  }
}
```

<Note>
  Nunca incluyas `businessId` en pipelines de analytics ni en ningún otro parámetro. El servidor lo inyecta automáticamente a partir de tu API key.
</Note>
