## ¿Qué es el MCP de Nippy?

El servidor MCP de Nippy expone todas las operaciones de tu negocio como herramientas que cualquier agente de IA puede invocar. En lugar de abrir la consola y navegar menús, le preguntas a Claude o Cursor directamente:

- "¿Cuántos premios se canjearon este mes?"
- "Crea una campaña de adquisición con ruleta para el producto X"
- "¿Qué productos están por debajo del stock mínimo?"

El servidor se encarga de la autenticación, el aislamiento multi-tenant y la ejecución. Tú solo haces preguntas.

## Clientes compatibles

El servidor usa **MCP sobre HTTP streamable** (JSON-RPC 2.0). Funciona con cualquier cliente que soporte el protocolo:

- **Claude Desktop** — integración nativa con herramientas
- **Cursor** — agente con acceso a tools en el editor
- **Agentes internos** — cualquier cliente Python/JS que implemente MCP
