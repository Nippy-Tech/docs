## Háblale a tu agente como si fuera parte de tu equipo

Con el MCP de Nippy, le puedes preguntar a Claude o Cursor cosas como *"¿cuántos premios se canjearon esta semana?"* o *"crea una campaña con ruleta para las mochilas nuevas"* — y lo hace. Sin abrir la consola, sin exportar Excel, sin esperar un reporte.

El agente traduce lo que le pides a las operaciones reales de tu negocio: consulta tu inventario, crea landing pages, configura ruletas de premios, revisa el progreso de tus cursos. Todo en segundos.

## ¿Con qué cliente funciona?

El servidor usa MCP estándar. Lo conectas una vez y funciona con:

- **Claude Desktop** — las tools aparecen en el chat, listas para usarse
- **Cursor** — tu agente en el editor tiene acceso directo a tus datos
- **OpenClaw**, **Hermes Agent** y cualquier otro cliente que hable MCP
