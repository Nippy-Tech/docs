# Overview

Documentación para integrar productos con Nippy. Usa el SDK para ejecutar mecánicas de gamificación desde tu aplicación, o conecta un cliente MCP para consultar y operar herramientas internas con lenguaje natural.

## Secciones principales

<CardGroup cols={2}>
  <Card title="SDK de gamificación" icon="code" href="/sdk/introduction">
    Integra campañas, spins, claims, webhooks y manejo de errores desde tu backend o frontend.
  </Card>
  <Card title="MCP" icon="plug" href="/mcp/introduction">
    Conecta clientes compatibles con MCP para consultar analytics, ruletas, flows, learning y supply.
  </Card>
</CardGroup>

## Empieza rápido

<CardGroup cols={2}>
  <Card title="Quickstart SDK" icon="rocket" href="/sdk/quickstart" horizontal>

  </Card>
  <Card title="Quickstart MCP" icon="terminal" href="/mcp/quickstart" horizontal>

  </Card>
</CardGroup>

## Referencia del SDK

<CardGroup cols={2}>
  <Card title="track()" icon="paper-plane" href="/sdk/track">
    Envía eventos de negocio y deja que Nippy evalúe reglas de campaña.
  </Card>
  <Card title="spin()" icon="rotate" href="/sdk/spin">
    Ejecuta un giro inmediato y recibe el resultado de forma síncrona.
  </Card>
  <Card title="getState()" icon="circle-info" href="/sdk/get-state">
    Consulta elegibilidad, cooldowns, spins restantes y claims pendientes.
  </Card>
  <Card title="claim()" icon="gift" href="/sdk/claim">
    Confirma premios físicos o digitales que requieren reclamación explícita.
  </Card>
</CardGroup>
