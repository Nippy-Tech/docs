## What it is

Nippy is a WorkerTech platform operating at scale in LATAM. The same gamification engine used in production for roulettes, points, and challenges is available as a B2B product for integration into your own app.

**Design principle:** one engine, many shells. Your product integrates the SDK. Nippy handles rules, probabilities, inventory, prize delivery, and webhooks.

You own the user experience. Nippy owns the engine behavior.

## Architecture

```text
Your app
   |
   | npm install @nippy/sdk
   v
NippyClient
   | track() spin() getState() claim()
   v
ms.nippy.la/v1/public/...
   |
   | signed webhooks
   v
Your webhook endpoint
```

## Activation modes

| Mode | When to use it |
|------|----------------|
| Automatic with `track()` | A user triggers an event and Nippy evaluates campaign rules. |
| Direct with `spin()` | Your app decides when to spin, usually after an explicit user action. |

## What the SDK does not do

- It does not render the animation. You control the UI.
- It does not store the result. Persist it from the webhook.
- It does not manage user identity. You pass the `userId` from your system.

## Requirements

- Node.js 18 or later
- An API key with the `npk_live_` prefix
- TypeScript 4.5+ recommended
