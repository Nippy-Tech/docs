Learning tools let an agent manage LMS operations from the MCP client.

## What you can do

- List courses and enrollment counts.
- Review student progress.
- Check exam results.
- Identify users who completed a course during a period.

## Example prompt

```text
Which users completed the onboarding course this week?
Include completion date and certificate status.
```
