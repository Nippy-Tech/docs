## What Nippy MCP is

Nippy MCP exposes the operational engine of the platform as tools that AI agents can call. Instead of opening a console, navigating menus, and exporting reports, you can ask directly:

- "How many active campaigns do we have this week?"
- "Create a roulette for the summer campaign with 500 points as the main prize."
- "Which products are below minimum stock in the Monterrey center?"

The agent executes the operation, retrieves data, and acts through the tools available to your business.

## How it relates to the SDK

The SDK and MCP access the same engine from different surfaces.

| | SDK | MCP |
|--|-----|-----|
| **Used by** | End users in your app | Your team or AI agent |
| **Accessed through** | npm package | MCP client |
| **Primary job** | Spin, win, claim | Create, analyze, manage |
