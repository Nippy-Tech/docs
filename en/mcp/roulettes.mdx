Roulette tools let an agent create, inspect, and manage gamification campaigns.

## What you can do

- List active roulettes.
- Create a roulette with prize probabilities.
- Review campaign status and inventory.
- Ask for performance summaries before changing a campaign.

## Example prompt

```text
Create a welcome roulette with three prizes:
500 points, a 10% discount, and keep participating.
Set the probabilities to 40%, 30%, and 30%.
```
