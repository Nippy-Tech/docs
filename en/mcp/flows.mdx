Flows tools manage registration pages used by acquisition and onboarding campaigns.

## What you can do

- Create registration flows.
- Configure fields and redirects.
- Review conversion by step.
- Compare flow performance across periods.

## Example prompt

```text
Show all registration flows created this month and rank them by conversion rate.
```
