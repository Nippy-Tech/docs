## May 2026 — Bilingual docs and public SDK reference

The documentation was reorganized to support Spanish and English from the global language switcher.

- **SDK** — public reference for `track()`, `spin()`, `getState()`, and `claim()`
- **Unified quickstart** — one entry point with SDK and MCP paths
- **Navigation** — hierarchical sidebar with getting started, SDK, MCP, and reference sections
- **Errors** — pages with causes, fixes, and examples per code
- **Homepage** — technical overview focused on documentation navigation

## May 2026 — Initial MCP release

First public version of the Nippy MCP server. Available verticals:

- **Analytics** — query operational data in natural language
- **Supply** — manage inventory, centers, and withdrawals
- **Roulettes** — create and manage prize roulettes
- **Flows** — registration landing pages for campaigns
- **Learning** — LMS with courses, progress, and certificates
