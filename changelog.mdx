## Mayo 2026 — Documentación bilingüe y SDK público

Se reorganizó la documentación para soportar español e inglés desde el selector global de idioma.

- **SDK** — referencia pública para `track()`, `spin()`, `getState()` y `claim()`
- **Quickstart unificado** — una sola entrada con rutas para SDK y MCP
- **Navegación** — sidebar jerárquico con secciones de inicio, SDK, MCP y referencia
- **Errores** — páginas con causas, soluciones y ejemplos por código
- **Homepage** — overview sobrio orientado a documentación técnica

## Mayo 2026 — Lanzamiento inicial

Primera versión pública del MCP de Nippy. Verticales disponibles:

- **Analytics** — consulta tus datos en lenguaje natural
- **Supply** — gestiona inventario, centros y retiros
- **Roulettes** — crea y administra ruletas de premios
- **Flows** — landing pages de registro para campañas
- **Learning** — LMS con cursos, progreso y certificados
