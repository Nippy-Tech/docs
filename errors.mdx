## Códigos de error

Todas las respuestas de error incluyen un campo `detail` con más contexto específico sobre qué falló. Si el error persiste, incluye ese detalle al reportarlo.

| Código | Significado | Qué hacer |
|--------|-------------|-----------|
| `401` | API key inválida o faltante | Verifica que el header `X-API-Key` tenga el valor correcto. Asegúrate de que sea una key con prefijo `npk_`. |
| `403` | Sin permisos para esta operación | Tu key no tiene acceso a esta vertical o acción. Revisa los permisos desde la Consola. |
| `429` | Demasiadas solicitudes | Espera unos segundos y reintenta. Si es recurrente, distribuye las llamadas en el tiempo. |
| `500` | Error interno del servidor | Reporta a `soporte@nippy.la` incluyendo el `request_id` de la respuesta y qué estabas haciendo. |

<Note>
  Todos los errores devuelven un campo `detail` con más contexto. Por ejemplo, un 401 puede decir `"X-API-Key header missing"` si olvidaste el header, o `"Invalid API key"` si la key está mal escrita.
</Note>

## Errores comunes en tools

### "MCP tools require tenant-bound auth"

Tu API key no es de tipo `npk_*`. Estás usando una key que no está ligada a un negocio específico. Asegúrate de usar la key que obtuviste en `https://console.nippy.la/settings/api-keys`.

### Sin resultados en una consulta de Analytics

Puede ser que no haya datos para el rango de fechas que pediste, o que el área de datos que elegiste no tenga información de ese tipo. Prueba con un rango más amplio o confirma que el área de datos es la correcta.

### "Roulette not found or does not belong to this business"

El ID de ruleta que pasaste no existe, o pertenece a otro negocio. Usa `roulettes_list_roulettes` para obtener los IDs de tus ruletas.

### Error de validación en retiros de Supply

El servidor valida que el centro y el producto pertenezcan a tu negocio, y que haya suficiente stock. Si ves un error, verifica los IDs con `supply_list_nippy_centers` y `supply_list_nippy_center_stocks` antes de reintentar.
